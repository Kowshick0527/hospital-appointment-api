# Hospital Appointment API

A REST API project for managing hospital patients, doctors, and appointments using TypeScript, PostgreSQL, and Prisma ORM.

## Features

- Patient CRUD operations
- Doctor management
- Appointment booking and management
- Search patients
- List doctors by specialty
- Update appointment status
- Cancel patient appointments

## Technologies Used

- Node.js
- TypeScript
- PostgreSQL
- Prisma ORM

## Run the Project

Install dependencies:

npm install

Run the test file:

npx ts-node src/test.ts

Seed the database:

npx prisma db seed
